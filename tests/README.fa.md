# تست‌ها

[English](README.md)

این‌ها اسکریپت‌هایی‌اند که هنگام توسعه برای راستی‌آزمایی نقش‌کد به کار رفتند. اسکریپت ساده‌اند، نه فریم‌ورک.

## نیازمندی‌ها
- Node نسخه‌ی ۱۸ یا بالاتر (تست واحد)
- Python 3 با Playwright برای Python و Chromium: `pip install playwright && python3 -m playwright install chromium`

## تست واحد (Node)

```
tests/run_unit_tests.sh
```

| فایل | بررسی |
|---|---|
| `unit/graph_test.mjs` | مربع، چهار دیوار جدا، دیوارهای متقاطع، دیوار آویزان، ضلع مشترک، ادغام زنجیره، مسدودشدن در اتصال T |
| `unit/graph_test2.mjs` | اتاق دارای سوراخ (مرز بیرونی، شمول)، یکدست‌سازی زنجیره |
| `unit/equivalence_test.mjs` | سازنده‌ی گراف تسریع‌شده با شبکه روی ۳۰۰ نقشه‌ی تصادفی همان آمار و مساحت وجه‌ها را به سازنده‌ی قدیمی همه‌جفت می‌دهد. برای اجرا یک `js/wallgraph.js` قدیمی را به‌صورت `unit/wallgraph_reference.mjs` ذخیره کنید (نسخه‌ای همراه است) |

## تست مرورگر (Chromium)

```
tests/run_browser_test.sh tests/browser/testS.py
```

اجراکننده پروژه را روی `http://localhost:8765` سرو می‌کند و اسکریپت‌ها فایل‌های موقت را در `/tmp/t/` می‌نویسند (اجراکننده آن را می‌سازد). هر اسکریپت نتیجه و فهرست خطاهای کنسول یا صفحه را چاپ می‌کند (`errs []` یا `[]` یعنی خطایی نیست). بعضی فایل‌ها ورودی‌هایی‌اند که اسکریپت‌های قبلی می‌سازند؛ اگر فایلی نبود `testB`، `testC2`، `testE`، `testG` را پیش از `testI` اجرا کنید.

| اسکریپت | حوزه |
|---|---|
| `testA`، `testA2` | طبقه‌ها، تاریخچه‌ی هر طبقه، ذخیره و بارگذاری، پرش تاریخچه |
| `testB`، `testB2` | Fillet، بازگردانی، شعاع محدودشده، آفست، DXF |
| `testC`، `testC2` | پنجره‌ی گراف دیوار، ادغام، تشخیص اتاق، Fillet روی دیوارهای ادغام‌شده، بارگذاری مجدد |
| `testD` | کشیدن گوشه، بازرنگ‌آمیزی پوسته، طبقه‌ی زیرین (از دکمه‌ی قدیمی پوسته استفاده می‌کند؛ پیش از استفاده‌ی مجدد به‌روز کنید) |
| `testE` | اتاق دارای سوراخ، یکدست‌سازی، فرم گراف خودکار، DXF همه‌ی طبقه‌ها، چاپ چندصفحه‌ای |
| `testF` | همه‌ی فلگ‌های امکانات روی false |
| `testG` | ماندگاری گراف، بازسازی از گراف، فایل‌های دست‌کاری‌شده و قدیمی |
| `testH` | واحدها، اعتبار PNG، SVG و PDF |
| `testI` | جدول متراژ، CSV، بررسی نقشه، پیوند اشتراک، مقایسه، سه‌بعدی |
| `testJ`، `testK` | مبلمان روی اتاق، قراردادن در و پنجره روی دیوار |
| `testL`، `testN`، `testO3` | رابط فارسی، ورودی‌های امپریال، بازگشت زبان |
| `testM`، `testV` | چیدمان موبایل، نوار ابزار، پنجره‌ی انتخاب، چرخش، مدیریت ارتفاع دیده‌شده |
| `testP` | پینچ دو انگشتی |
| `testS` | تنظیمات، ماندگاری، ذخیره‌ی خودکار، خروجی، ورودی، بازنشانی |
| `testX` | تزریق HTML از طریق نام لایه در فایل پروژه |
| `risk`، `risk2` | ترسیم لمسی، چرخش، پوسته‌ی سیستم، حافظه‌ی پر، ورودی‌های خراب، سقف تاریخچه |
| `perf`، `perf2` | زمان‌سنجی روی نقشه‌های بزرگ و متراکم مصنوعی (`python3 tests/browser/perf.py 80`) |

## پوشش داده‌نشده
Firefox، Safari و گوشی‌های واقعی در محیط ساخت در دسترس نبودند. اسکریپت‌های مرورگر را با `p.firefox` یا `p.webkit` به‌جای `p.chromium` در جاهایی که آن مرورگرها نصب‌اند اجرا و لمس را روی دستگاه تست کنید.
